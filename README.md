
## Student Management System in C

## Project Overview
The Student Management System is a console-based application developed in C. It helps manage student records efficiently using file handling. The program allows users to add, display, search, update, and delete student records. All records are stored permanently in a text file.

## Features
- Add Student
- Display All Students
- Search Student by ID
- Update Student Details
- Delete Student Record
- Save Data Using File Handling
- Automatically Load Data When the Program Starts

## Technologies Used
- C Programming
- GCC Compiler
- Visual Studio Code
- File Handling (`students.txt`)

## How to Run

### Compile

```bash
gcc main.c -o student
```

### Run (Windows)

```bash
.\student.exe
```

### Run (Linux/macOS)

```bash
./student
```
